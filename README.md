# System 1 benchmark

The complete runnable dashboard is on the [codex/system-one-benchmark branch](https://github.com/oks-erm/s1bench/tree/codex/system-one-benchmark).

[Download all files as ZIP](https://github.com/oks-erm/s1bench/archive/refs/heads/codex/system-one-benchmark.zip), extract, install Python 3.10 or later, and run `py start.py` on Windows or `python3 start.py` on macOS/Linux.

The dashboard creates one local configuration and starter data. Add your models and labelled data in the GUI. No benchmark starts automatically.
